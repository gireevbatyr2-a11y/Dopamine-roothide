# Инструменты, использованные в этом аудите

- `gh` CLI / GitHub REST API: метаданные репозитория, текущий Git tree, коммиты, Actions run и artifact metadata.
- Ручная проверка конфигурации: `README.md` и `.github/workflows/main.yml`.

В этом аудите не запускались Xcode, сборка проекта, Ghidra, jailbreak, код на устройстве или тесты приложения. Новые skills/MCP-интеграции не устанавливались и не подключались. Поэтому результаты ограничены инвентаризацией метаданных и проверкой статуса Actions.
