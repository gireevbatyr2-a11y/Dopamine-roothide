# Поток GitHub Actions

Workflow `.github/workflows/main.yml` запускается на `push`, `pull_request` и вручную. Он использует GitHub-hosted macOS runner, выбирает `latest-stable` Xcode, проверяет репозиторий вместе с подмодулями, настраивает зависимости и запускает проектную сборку. В конце workflow загружает IPA и TIPA как отдельные Actions artifacts.

Успешный запуск подтверждает завершение CI job и наличие заявленных artifacts. Он не подтверждает запуск приложения на устройстве и не является доказательством побайтовой воспроизводимости. Схема: [diagrams/build-flow.mmd](diagrams/build-flow.mmd).

Это краткое описание существующего workflow; оно намеренно не воспроизводит эксплуатационные процедуры или низкоуровневые инструкции.
