# Обзор архитектуры

Это карта крупных границ репозитория, а не описание внутреннего выполнения привилегированных компонентов.

- `Application/` — iOS-приложение, Xcode project, интерфейс, ресурсы и локализации.
- `BaseBin/` — вспомогательные компоненты, ресурсы и правила упаковки, используемые сборкой.
- `.github/workflows/` — конфигурация GitHub Actions.
- `.gitmodules` — объявления внешних зависимостей; фактическое содержимое подмодулей определяется отдельными gitlink SHA.
- `README.md` и `BUILD.md` — документация проекта и сборочного процесса.

Высокоуровневая связь: исходники приложения, вспомогательные компоненты и зафиксированные внешние зависимости обрабатываются CI workflow; результатом являются архивы приложения `.ipa` и `.tipa`. GitHub Tree API показывает ссылки на подмодули как отдельные записи и не включает их внутренние файлы в корневой подсчёт.
